# Book Catalog

A simple web page that displays a catalog of books in a table, showing each book's title, author, genre and publication year. Built as part of the freeCodeCamp curriculum.

## Live Demo

[View the project](https://aqeelahlabs.github.io/A-Book-Catalog-Table/)

## Features

- A table with column headings for Title, Author, Genre and Publication Year
- Five books listed, each in its own row
- A footer row showing the total number of books

## What I Practised

- Structuring a basic HTML5 page
- Building a data table with the `table`, `tr`, `th` and `td` elements
- Organising a table into `thead`, `tbody` and `tfoot` sections
- Spanning a cell across several columns with `colspan`
- Making the page responsive with the viewport `meta` tag

## Built With

- HTML5
